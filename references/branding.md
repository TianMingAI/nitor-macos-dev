# Nitor branding

- Owner: Nitor; GitHub: https://github.com/TianMingAI; public account, website, email and QR codes: not supplied, hidden by default.
- `assets/brand.json` is copied to `Resources/About/brand.json` in every new project. Edit the skill copy for future projects only when asked; edit the project copy for an existing app.
- Website and feedback email are optional and hidden when empty. Do not guess them.
- Optional images: explicitly supplied `assets/brand/wechat-qr.jpg` and `assets/brand/reward-qr.png`. No images are bundled by default. The generator copies each independently; absent images create no cards or blank space.
- Names default to Nitor<词>, a short English name, `ai.nitor.<slug>`, and `TianMingAI/nitor-<slug>`. Do not change an existing app's bundle ID or update feed just to rebrand it.
- Product branding belongs to Nitor. Original MIT copyright remains in LICENSE and NOTICE.md, including generated projects; do not present upstream work as newly authored.
- The About privacy statement must match actual app behavior, especially if cloud APIs are added.
